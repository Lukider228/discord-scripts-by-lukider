# Discord Scripts

Пара юзерскриптов для Discord, которые я собрал для себя и решил выложить — вдруг кому пригодится. Работают в браузерной версии Discord через Tampermonkey/Violentmonkey.

## Что внутри

### 🗑️ Discord Mass Deleter (v2.1)

Массовое удаление своих сообщений — на сервере, в канале или личке. Это переработка известного скрипта [Undiscord (victornpb/deleteDiscordMessages)](https://github.com/victornpb/deleteDiscordMessages): я перевёл его на русский, перерисовал интерфейс (glassmorphism, боковая панель) и подчистил утечки памяти, из-за которых оригинал подтормаживал на длинных чистках.

Что умеет:

- удалять только свои сообщения или сообщения конкретного автора;
- фильтры: по датам, по тексту, по наличию ссылок или файлов;
- **холостой запуск (dry run)** — сначала показывает, *что* удалится, ничего не трогая. Советую всегда начинать с него;
- прогресс-бар и подробный лог: видно каждое удалённое сообщение;
- архивные ветки и системные сообщения (пины, приглашения) пропускает сам — Discord всё равно не даёт их удалять.

Как пользоваться: нажми иконку корзины в тулбаре Discord, заполни ID сервера/канала (есть кнопка автозаполнения), настрой фильтры → «Холостой запуск» → если всё ок, «Запустить удаление».

### 🌟 Social Copilot AI (v2.0)

Анализ переписки с помощью ИИ (Google Gemini). Открываешь диалог, запускаешь — скрипт читает последние 50 сообщений и выдаёт:

- **Vibe Check** — общая атмосфера переписки в процентах;
- **психологический портрет** собеседника — черты характера, тип привязанности;
- **чат с ИИ** — можно задавать вопросы про эту переписку, ответы учитывают контекст.

Если в чате больше двух человек, анализируется групповая динамика.

Нужен бесплатный API-ключ Gemini: [Google AI Studio](https://aistudio.google.com/) → «Create API Key». Ключ вставляется в настройки скрипта и хранится только локально в твоём браузере — наружу он не уходит, запросы идут напрямую в Google.

## Установка

1. Поставь расширение [Violentmonkey](https://violentmonkey.github.io/) или [Tampermonkey](https://www.tampermonkey.net/).
2. Открой файл скрипта в этом репозитории и нажми **Raw** — расширение само предложит установить.
3. Открой Discord в браузере: в тулбаре справа сверху появятся две новые иконки — корзина (Mass Deleter) и 🌟 (Social Copilot).

## Дисклеймер

Оба скрипта работают от имени твоего аккаунта, а любая автоматизация пользовательского аккаунта формально противоречит [условиям Discord](https://discord.com/terms). На практике удаление собственных сообщений с разумными задержками (они тут встроены) проблем не вызывало, но используешь на свой страх и риск. И само собой — Mass Deleter удаляет безвозвратно, начинай с холостого запуска.
